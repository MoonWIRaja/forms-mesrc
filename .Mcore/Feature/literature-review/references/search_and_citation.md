# Search and citation workflow

Choose bibliographic sources that match the field and question. Use the active host's actual search or browser tools, public scholarly APIs, or an already configured research integration; do not assume a particular provider, CLI, account, or tool schema is available.

For a reproducible review, record each database or source, exact query, search date, filters, result count, and retrieval outcome. Keep database search distinct from supplementary web discovery. Treat snippets and ranked results as leads, not as full-text evidence or proof of complete coverage.

Deduplicate records while retaining source provenance. Verify titles, authors, publication date, venue, identifiers, corrections, and retractions against the primary record or publisher. Preserve not-retrieved reports and failed searches in the flow record. Never invent missing citation fields.

Bundled `database_strategies.md` documents source-specific public APIs. Follow each service's current terms, rate limits, and optional key requirements. Keys are not required by this workflow and must not be included in project files or transcripts.
