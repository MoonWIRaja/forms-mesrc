# Illustrative literature-review workflow

This example shows the record structure for a review. It does not establish that a real search is exhaustive.

1. Define the question, populations or phenomena, eligible designs, date range, and exclusions before searching.
2. Select field-appropriate sources such as PubMed, Crossref, OpenAlex, arXiv, or a discipline-specific database. Use the search or browser tools actually available, or query the source's documented public interface.
3. Record each exact query, date, filter, result count, and retrieval limitation. Keep supplementary web discovery separate from formal database searches.
4. Deduplicate bibliographic records while retaining source provenance. Screen against the predeclared criteria and report full-text retrieval failures.
5. Extract study-level methods, populations, outcomes, estimates, uncertainty, and limitations. Verify claims against the full source where accessible.
6. Present the flow counts and synthesis with links to the underlying records. Distinguish evidence from interpretation and name the search boundary.
