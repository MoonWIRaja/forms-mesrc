# BMad Method in MemoryCore

This is a MemoryCore adaptation inspired by [BMad Method](https://github.com/bmad-code-org/bmad-method), not a full port. It covers the software/product lifecycle from intent and optional discovery through requirements, UX/architecture, story breakdown, bounded implementation, review, course correction, integration, retrospective, and handoff. The provider-neutral operating rules are in `../Work-Flow/SKILL.md`; the step-by-step path is `../Work-Flow/references/lifecycle.md`. Follow the smallest path that safely fits the work, preserve acceptance checks and decision ownership, and use MemoryCore helpers for cross-session memory.

Run this native workflow through the current AI with the existing MemoryCore helper. No BMad installer or extra account is needed. Use `.Mcore/skills-and-mcp.md` for routing and integration details. Do not create provider folders in this project.
