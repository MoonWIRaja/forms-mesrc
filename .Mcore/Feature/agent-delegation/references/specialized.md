# Specialized work and capability limits

The domain entries below describe workflows absorbed directly by the Main Solo Agent; they do not supply external credentials or datasets automatically. Discover installed capabilities first. When one is absent, use a verified local method or explain the specific gap.

| Domain | Solo-Agent Working Approach |
|---|---|
| Product, engineering, design, research | Absorb the relevant specialist lens from `msitarzewski/agency-agents` and `obra/superpowers` inline; keep ownership and acceptance criteria explicit in `PLAYBOOK.md`. |
| Critical thinking & root-cause analysis | Route via `tjboudreaux/cc-thinking-skills` (`thinking-model-router`) using the 4-tag Micro-Token Cognitive Scratchpad (`MTCS`). |
| Prompt engineering | Run the `nidhinjs/prompt-master` 9-dimension extraction, Model Recency Gate, and token audit. |
| Copywriting & de-slopping | Run the `ItsssssJack/SlopMonster` 4-step linter (`deslop.py`) and human-grade rewrite workflow. |
| Security & reverse engineering | Use Strix-Security, `thinking-red-team`, and `morluto/rea` (`rea-agents`) within authorized scope; inspect real code, binaries, and evidence. |
| Desktop & sandbox automation | Use `trycua/cua` (`cua-driver`, `cua sb`, `lume`, `cua-bench`) directly from the Main Agent without stealing cursor focus. |
| Sales, marketing, customer support | Ground claims in approved product/customer evidence; never invent proof, testimonials, or contacts. |
| Finance and accounting | Confirm period, currency, entity and source ledger; reconcile balances, check calculations and preserve an audit trail. |
| Legal, compliance and policy | Identify jurisdiction, document version and actual question; research applicable sources and separate factual assistance from unsupported certainty. |
| Analytics and SQL | Confirm schema, grain, permissions and dialect; prefer read-only investigation, verify join cardinality, aggregation and numerical conclusions. |
| Incidents and operations | Apply `thinking-ooda` + `thinking-kepner-tregoe`; establish impact, timing and evidence; separate diagnosis from authorized remediation and preserve rollback options. |
| AI, RAG, MCP & skill engineering | Apply `rohitg00/ai-engineering-from-scratch` first-principles harnesses and store verified scripts in `toolbox/`. |
