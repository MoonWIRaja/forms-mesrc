# AGENTS.md — Single Agent System (Mandatory Every-Turn)

1. **Satu agen utama** — Tanpa sub-agen, tanpa multi-agent swarm.
2. **Tiada login** — Pengguna dikenal pasti dengan `user_id` ringkas. Sokongan pelbagai pengguna.
3. **Lima wajah berpikir** — Analis → Pembangun → Penguji → Keselamatan → Penyusun. Guna secara berturutan untuk tugas besar.
4. **Memori sebelum ubah kod** — Tulis task, folder, fungsi, baris, cara, mengapa ke memori & diari sebelum sentuh kod.
5. **Memori selepas ubah kod** — Simpan apa yang diubah, baris sebelum & selepas, ujian, keselamatan, nota penyerbakan.
6. **Penyerbakan antara AI** — AI baru baca memori/diari terakhir untuk tahu apa yang dilakukan & mengapa.
7. **Serapkan semua skills** — agent-delegation, Agency-Roles, agent-core, design-taste-frontend, Hallmark-Design, harness2, Understand-Anything, andrej-karpathy-skills — sebagai wajah berpikir inline, bukan agen terasing.
