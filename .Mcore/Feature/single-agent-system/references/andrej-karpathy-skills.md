# Andrej Karpathy Skills — multica-ai

Sumber: https://github.com/multica-ai/andrej-karpathy-skills

## Peran dalam Single Agent System

Koleksi skills AI daripada Andrej Karpathy diserap ke dalam single agent sebagai wajah berpikir inline. Tidak mencipta agen terasing. Setiap skill menjadi salah satu daripada lima wajah berpikir:

| Karpathy Skill | Wajah Berpikir Single Agent |
|----------------|------------------------------|
| Code understanding | Analis / Penyelidik |
| Code implementation | Pembangun / Peniaga Kod |
| Testing and validation | Penguji (QA) |
| Security review | Pemulih Keselamatan |
| Documentation and explanation | Penyusun / Editor |

## Cara Guna

1. Pilih skill yang relevan dengan langkah tugasa terkini
2. Guna skill sebagai "lensa" berpikir, bukan agen terasing
3. Semua output tetap daripada satu agen utama
4. Rekodkan dalam memori/diari sebagai biasa

## Peraturan

- Tiada sub-agen, walaupun skills berganda digunakan
- Semua skills berjalan secara inline dalam satu sesiil
- Rekodkan mana skill yang digunakan dalam `persona_used`
